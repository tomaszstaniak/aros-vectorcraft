# Documentation

- [Development](development.md): fetch, materialize, build per target, package, verify.
- [Patches](patching.md): how the AROS changes are kept and exported.

Release packaging inputs are in `packaging/`: `release.json` (version, notices, per-target
profile and system names), `ReadMe.txt` (the user's ReadMe in each package), `notices/`
(the AROS notice of each target), `AROS-LICENSE.txt` and `RELEASE-NOTES.md`.
